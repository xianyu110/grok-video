## 核心功能一：文生视频

要更完整的参数，打开视频工作室。左边写提示词，右边是生成结果预览板。

工作室里可以选：

- **画幅**：16:9、9:16、1:1
- **时长**：6 秒或 10 秒
- **分辨率**：480p、720p、1080p（页面会提醒：1080p 会按请求发送，仅支持到 720p 的模型可能会拒绝）

视频模型目前有四个，默认是较新的 **Imagine Video 1.5**（`grok-imagine-video-1.5`），文生视频在服务接受时可以请求 1080p。另外还有最初的 **Grok Video**、**Imagine 1.5 预览**，以及独立目录的 **Grok Video 1.5**。

没登录时，按钮下方会写着「6s · 访客免费预览」。勾选内容政策确认后即可生成；访客额度用完，再登录用积分继续。
